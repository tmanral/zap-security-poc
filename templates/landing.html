Security Awareness

What is OWASP?

OWASP (Open Worldwide Application Security Project) is a nonprofit, community-driven organization dedicated to improving software and web application security through open resources, guidance, and education.

What is the OWASP Top 10?

The OWASP Top 10 is a widely referenced awareness document—not a scanner—that highlights common categories of web application security risks. It helps developers and security professionals prioritize what to look for when building and testing applications.

OWASP Top 10:2021 — Risk Categories

A01

Broken Access Control

Users can access data or actions beyond their intended permissions.

A02

Cryptographic Failures

Sensitive data is exposed due to weak or missing encryption.

A03

Injection

Untrusted input is interpreted as commands, queries, or code.

A04

Insecure Design

Security gaps are introduced during design rather than implementation.

A05

Security Misconfiguration

Unsafe defaults, open cloud storage, or verbose error messages.

A06

Vulnerable & Outdated Components

Libraries, frameworks, or dependencies with known vulnerabilities.

A07

Identification & Authentication Failures

Weak login, session, or credential recovery mechanisms.

A08

Software & Data Integrity Failures

Updates or data are accepted without verifying their integrity.

A09

Logging & Monitoring Failures

Suspicious activity goes undetected due to insufficient logging.

A10

Server-Side Request Forgery

The server is tricked into fetching unintended internal resources.

WebGuard helps users identify common web application security risks through a structured testing workflow. It does not detect every category above automatically—use findings as a starting point for further review.
